# 予約管理マニュアル

士道 SHIDO Gallery Paris のブース予約サイト(`/booking`)に届いた申込みを、確認・確定・お断りするまでの手順書です。

このサイトに管理画面はなく、**Googleスプレッドシートを直接編集すること**がそのまま予約管理になります。

- 対象: 士道 SHIDO Gallery Paris オーナー・運営担当
- 最終更新: 2026年9月6日 / version 1.1

## 1. 概要

お客様がサイトのカレンダーから希望日・ブースを選んで申込むと、内容は自動的に2か所へ送られます。**データの保存先はGoogleスプレッドシートのみ**で、メールは通知(お知らせ)であって記録ではありません。

1. お客様が予約フォームを送信 — `/booking` のカレンダーで日付・ブースを選び、氏名や連絡先を入力
2. スプレッドシートに1行追加 — ステータスは自動で「仮予約」。これが唯一の予約データ本体
3. あなたにメール通知 — `nipponbudomiyazaki@gmail.com` 宛に予約内容が届く(Resend経由)

> メール送信が何らかの理由で失敗しても、スプレッドシートへの保存は先に完了しているため予約自体は失われません。ただしメールだけを頼りにせず、時々スプレッドシートを直接開いて確認する習慣をおすすめします。

## 2. 日常の運用フロー

新しい申込みが入ってから、対応を終えるまでの4ステップです。

1. **通知メールに気づく** — 件名は「【新規予約】YYYY-MM-DD ブースX / 氏名様」の形式。本文に希望日・ブース・氏名・連絡先・用途備考が記載されています。
2. **スプレッドシートで該当行を確認** — 「予約」シートを開き、申込日時が最新の行を確認。連絡先の記載ミスや希望日の重複がないか目視でチェックします。
3. **ステータス列を書き換える** — 受け入れる場合は該当セルを「確定」に、お断りする場合は「却下」に書き換えます。何もしなければ「仮予約」のままです。
4. **お客様へ直接連絡する** — サイトはお客様への自動返信を送りません。連絡先(メール・電話)へ、確定または見送りの旨を直接伝えてください。

## 3. スプレッドシートの見方

シート名は必ず「予約」のままにしてください。名前を変えるとサイトがデータを読み書きできなくなります。

| 列 | 内容 | 編集 |
|---|---|---|
| 予約ID | 申込み時刻から自動生成される固有番号 | 編集不要 |
| 申込日時 | お客様が送信した日時(自動記録) | 編集不要 |
| 希望日 | ご希望の展示日(YYYY-MM-DD) | 編集不要 |
| ブース | A〜Fのいずれか | 編集不要 |
| 氏名 / 連絡先 | お客様の入力内容 | 編集不要 |
| 用途備考 | 展示内容や要望の自由記述 | 編集不要 |
| ステータス | 仮予約 / 確定 / 却下 | **ここだけ手動で編集** |

## 4. ステータス管理の注意点

カレンダーの空き状況は、このステータス列の文字列を見て自動計算されています。「確定」と「仮予約」は、どちらもその日・そのブースを「空きなし」として表示します。「却下」にした行だけ、翌読み込みから即座に「空き」へ戻ります。

> **⚠️ 重要**
> ステータスは全角で「仮予約」「確定」「却下」と**一字一句そのまま**入力してください。誤字や余分な空白があると、予約が存在するのにカレンダー上は「空き」と表示されてしまい、二重予約の原因になります。プルダウンによる入力補助はまだ用意されていません。

判断に迷う申込みを「仮予約」のまま長期間放置すると、その日・ブースは他のお客様から予約できない状態が続きます。できるだけ早めに確定か却下を決めることをおすすめします。

## 5. メール通知について

新しい予約がスプレッドシートに書き込まれた直後、**`nipponbudomiyazaki@gmail.com`** 宛にResendというメール配信サービス経由で通知が送られます。宛先はコード内に固定で書かれており、サイト側の設定画面はありません。

**届かないときは:**

- まず迷惑メールフォルダを確認してください。
- [Resendダッシュボードの「Logs」](https://resend.com/emails)で送信履歴とエラー内容を確認できます。
- Vercelの環境変数 `RESEND_API_KEY` が期限切れ・未設定になっていないか確認してください。未設定でも予約自体はスプレッドシートに保存されており、失われることはありません。

## 7. サイトの構成

- **トップページ(`/`)** — ギャラリー紹介、外観・内観写真、地図、料金表
- **予約ページ(`/booking`)** — 月間空き状況カレンダー、申込フォーム、フロア配置図

お客様向けの管理画面やマイページはありません。予約状況の管理はすべて本マニュアルの通り、スプレッドシート側で行います。

## 8. サイトを編集したい場合

このサイトに「管理画面」はありません。文章・写真・料金・営業時間などを変えたい時は、**Claude Code(AIアシスタント)にVSCode上で日本語で頼んで、コードごと書き換えてもらう**のが唯一の編集方法です。

### 編集の流れ

1. パソコンでVSCodeを開き、このプロジェクトのフォルダ(`my-new-app-test`)を開く
2. Claude Codeのチャット欄に、変えたい内容をそのまま日本語で伝える
3. Claude Codeが該当するファイルを編集する
4. 手元で `npm run dev` を実行し、`localhost:3000` で見た目を確認する(Claude Codeが自動でやってくれることが多い)
5. 問題なければ「これで本番にも反映して」と伝える → GitHubへpush → Vercelが自動で再公開(通常1分程度)

> 一度にたくさんの変更を頼まず、一つずつ確認しながら進めると安全です。気に入らない変更は「元に戻して」と伝えれば、git の履歴から直前の状態に戻せます。

### よくある編集依頼の例

| やりたいこと | 頼み方の例 | 変更されるファイル(参考) |
|---|---|---|
| 料金を変えたい | 「ブースCの週末料金を€550にして」 | `lib/galleryData.ts` |
| 営業時間・定休日を変えたい | 「営業時間を10:00〜18:00にしたい」 | `lib/galleryData.ts` |
| 写真を差し替えたい | 新しい画像を渡して「トップページのこの写真をこの画像に差し替えて」 | `public/` 内の画像、`app/page.tsx` |
| 文章を直したい | 「トップページのこの一文を、もっと簡潔にして」 | `app/page.tsx` など |
| 新しい入力項目を増やしたい | 「予約フォームにアレルギー情報の欄も追加したい」 | フォーム・保存処理・スプレッドシートの列 |

環境変数(APIキーなど)に関わる変更は、Vercel側の環境変数画面も合わせて更新する必要がある場合があります。その際はClaude Codeが必要な手順を教えてくれます。

> 会話だけでゼロからこのサイトを作った際の詳しい流れは、社内共有用ガイド「ゼロから作る予約サイト」も参照してください。

## 9. トラブルシューティング

| 症状 | 考えられる原因 | 対応 |
|---|---|---|
| 通知メールが届かない | APIキー未設定・期限切れ、迷惑メール判定 | Resendの Logs を確認 → 届かなくても予約自体はシートに保存済み |
| 予約カレンダーがエラーで表示されない | Googleスプレッドシートの共有設定、または環境変数の誤り | サービスアカウントへの編集者共有、`GOOGLE_SHEET_ID` を確認 |
| 確定/却下にしたのに反映されない | ステータス欄の誤字・余分な空白 | 「確定」「却下」と全角で正確に再入力し、ページを再読み込み |
| 月曜日を選べない | 仕様通り(定休日は予約不可) | 対応不要 |

## 11. 技術情報(開発者向け)

将来、別の開発者に引き継ぐ際に必要な情報です。日常運用では読む必要はありません。

**環境変数**(値は非公開・各サービスで発行し直せます)

| 変数名 | 用途 |
|---|---|
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | スプレッドシート読み書き用サービスアカウント |
| `GOOGLE_PRIVATE_KEY` | 同サービスアカウントの秘密鍵 |
| `GOOGLE_SHEET_ID` | 予約データを保存するスプレッドシートのID |
| `RESEND_API_KEY` | 通知メール送信用APIキー |
| `RESEND_FROM_EMAIL` | 通知メールの送信元アドレス |

**主要ファイル**

| ファイル | 役割 |
|---|---|
| `app/api/bookings/route.ts` | 予約の取得(GET)・新規登録(POST) |
| `lib/googleSheets.ts` | スプレッドシートの読み書き |
| `lib/notifyEmail.ts` | Resendによる通知メール送信 |
| `lib/galleryData.ts` | ブース仕様・料金・定休日ロジック |
